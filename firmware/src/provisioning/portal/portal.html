    Which PC should it wake?

    Wake-on-LAN identifies a machine by its network adapter's MAC address.

    Where do I find it?

    Windows — Settings › Network & internet › your adapter, then read Physical address (MAC). Use the wired adapter if the PC has one; Wi-Fi wake is unreliable by design.

    macOS — System Settings › Network › your adapter › Details › Hardware.

    Linux — ip link, and read the link/ether line.
